# ขั้นตอนทำรายงานด้วย AI (Markdown → LaTeX → PDF)

ตามที่อาจารย์กำหนด: ระหว่างทำงาน ทีมบันทึกผลแต่ละขั้นเป็นไฟล์ `.md` ไว้ในโฟลเดอร์ `md/`
เมื่อทำเสร็จ ให้ AI (Claude) อ่าน `.md` ทั้งหมดแล้วเรียบเรียงเป็น LaTeX และรันใน Docker เพื่อสร้าง PDF

## Prompt ที่ใช้สั่ง AI

```text
อ่านไฟล์ Markdown ทั้งหมดในโฟลเดอร์ docs/md ตามลำดับชื่อไฟล์
แล้วเรียบเรียงเป็นรายงานโครงงานภาษาไทยในรูปแบบ LaTeX สำหรับคอมไพล์ด้วย XeLaTeX

ข้อกำหนด:
- ใช้ documentclass report กระดาษ A4 ฟอนต์ไทย Sarabun (อยู่ใน docs/fonts สัญญาอนุญาต OFL) ตั้ง Script=Thai ให้วางสระ/วรรณยุกต์ถูกตำแหน่ง ฟอนต์โค้ด TlwgTypo ตัดคำไทยด้วย \XeTeXlinebreaklocale "th"
- ลำดับ: ปก (จาก 00-cover.md) → คำนำ → สารบัญอัตโนมัติ → บทที่ 1–7 → บรรณานุกรม → ภาคผนวก
- หัวข้อใน .md มีเลขบทและเลขข้อแล้ว ห้ามใส่เลขซ้ำ แต่ให้ขึ้นในสารบัญ
- ตารางต้องตัดบรรทัดได้ไม่ล้นขอบกระดาษ · โค้ดใช้กรอบและตัดบรรทัดยาว · รูปปรับให้พอดีความกว้างหน้า
- ห้ามแต่งข้อมูลเพิ่มจากที่มีในไฟล์ .md ข้อความในวงเล็บ [ ] ให้คงไว้ให้ทีมเติมเอง
- เตรียม Dockerfile และสคริปต์ build ที่ติดตั้ง TeX Live + ฟอนต์ไทย แล้วสร้าง report.pdf
```

## ผลลัพธ์ที่ AI สร้าง

- `tools/md2tex.py` แปลง `md/*.md` เป็น `latex/chapters/*.tex` (ใช้ pandoc แล้วปรับรูปแบบหัวข้อ ตาราง โค้ด รูป)
- `latex/main.tex` โครงเล่ม: ปก คำนำ สารบัญ และนำบทต่างๆ มารวม
- `Dockerfile` + `build.sh` ติดตั้ง TeX Live, ฟอนต์ไทย (fonts-thai-tlwg), pandoc แล้วคอมไพล์

## สร้าง PDF

ต้องมี Docker (Windows/macOS ใช้ Docker Desktop) แล้วรันในโฟลเดอร์ `docs`:

```bash
docker build -t cs-buu-report .
docker run --rm -v "$PWD":/work cs-buu-report          # Linux / macOS / Git Bash
docker run --rm -v "${PWD}:/work" cs-buu-report        # Windows PowerShell
```

ได้ไฟล์ `docs/report.pdf` · แก้เนื้อหาที่ไฟล์ `.md` แล้วรันคำสั่งสุดท้ายซ้ำได้เลย
