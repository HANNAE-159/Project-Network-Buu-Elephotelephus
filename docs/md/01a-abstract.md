## บทคัดย่อ

โครงงานนี้ติดตั้งเว็บไซต์ WordPress บนเซิร์ฟเวอร์เสมือนของ Google Cloud ด้วยตนเอง เพื่อประชาสัมพันธ์สาขาวิชาวิทยาการคอมพิวเตอร์ คณะวิทยาการสารสนเทศ มหาวิทยาลัยบูรพา และรักษาความปลอดภัยตามโจทย์ 3 ขั้น ได้แก่ การให้บริการผ่าน HTTPS พร้อมตั้งค่า SSH ให้ปิดการเข้าด้วย root และใช้กุญแจสาธารณะเท่านั้น การทำ firewall ที่รับการเชื่อมต่อเฉพาะจากหมายเลข IP ในประเทศไทย และการพัฒนาเว็บไซต์ที่ทีมแก้ไขเนื้อหาได้เอง

คณะผู้จัดทำเขียนสคริปต์ติดตั้งระบบ nginx, PHP-FPM, MySQL และ WordPress ขอใบรับรองจาก Let’s Encrypt ด้วยวิธี DNS-01 สร้าง geo-firewall ด้วย ipset และ iptables จากรายการ IP ไทยของ APNIC จำนวน 1,167 ช่วง และป้องกันหลายชั้นด้วย fail2ban, rate limit, 2FA และการตั้งค่าเว็บเซิร์ฟเวอร์ นอกจากนี้ได้พัฒนาระบบ secdash ที่อ่าน log 4 แหล่ง จัดประเภทเหตุการณ์น่าสงสัย แสดงผลเป็น dashboard ในหลังบ้าน และใช้ Google Gemini สรุปเป็นภาษาไทยทุกชั่วโมง

ผลการทดสอบพบว่าเว็บไซต์ใช้ TLS 1.3 SSH ปฏิเสธ root และรหัสผ่าน จุดทดสอบจากต่างประเทศที่เลือกใช้ทุกจุดเชื่อมต่อไม่ได้ และสคริปต์ตรวจความปลอดภัยให้ผล FAIL 0 การตรวจเพิ่มเติมวันที่ 29 ตุลาคม 2569 เวลา 23:32 น. พบคำขอ HTTP 1,818 ครั้งใน 24 ชั่วโมง ตรงกับผลรวมสถานะ HTTP และพบเหตุการณ์น่าสงสัยจากหลายแหล่ง log 7,732 เหตุการณ์ ซึ่งรวม GEO-BLOCK 6,367 เหตุการณ์ การทดสอบนำเข้าข่าวซ้ำสองรอบไม่เพิ่มโพสต์ซ้ำ ข้อจำกัดคือ geo-firewall กันผู้โจมตีที่ใช้ IP ไทยไม่ได้ และระบบตรวจจับทำงานตามกฎที่กำหนดไว้ล่วงหน้า

**คำสำคัญ:** WordPress, ความปลอดภัยเว็บเซิร์ฟเวอร์, geo-firewall, SSH, การตรวจจับการโจมตี, LLM
