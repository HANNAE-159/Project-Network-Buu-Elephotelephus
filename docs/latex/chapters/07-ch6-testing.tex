\section*{6.2 การโจมตีที่ตรวจพบจริง}\addcontentsline{toc}{section}{6.2 การโจมตีที่ตรวจพบจริง}

ข้อมูลจาก dashboard เมื่อวันที่ 26 ตุลาคม 2569 (ย้อนหลัง 7 วัน) {[}อัปเดตตัวเลขก่อนส่ง{]}

\begin{itemize}
\tightlist
\item
  พบ IP น่าสงสัย 11 หมายเลข และระบบแยก IP ของทีมที่ login สำเร็จออก 5 หมายเลข
\item
  อันดับ 1 คือ 130.12.180.117 (ต่างประเทศ) สแกนหาไฟล์ลับ 61 ครั้ง เช่น .env และไฟล์คอนฟิก Docker คะแนนความเสี่ยง 244 ไฟล์เหล่านี้ถูก nginx ปฏิเสธหรือไม่มีอยู่บนเซิร์ฟเวอร์
\item
  พบการไล่หาชื่อผู้ใช้ผ่าน REST API (/wp/v2/users) และ author query จาก IP ที่ไม่ใช่ทีม
\item
  ใน 24 ชั่วโมงก่อนตรวจ ไม่พบ SSH หรือ WordPress login ที่ไม่สำเร็จ (ค่าเป็น 0 ทั้งคู่)
\end{itemize}
